# Guía rápida: cambiar textos y horario de la web

## 1. Entra al panel

Ve a `tu-dominio.com/admin` e introduce la contraseña que te haya dado Kodarvia.

## 2. Cambia lo que necesites

Verás la página dividida en bloques (cabecera, portada, servicios, precios, equipo, preguntas frecuentes, contacto, legales). Toca el texto que quieras cambiar y escribe el nuevo — se guarda solo, no hace falta pulsar ningún botón.

Para cambiar el **horario**, ve al bloque "Contacto" y edita el campo "Horario".

## 3. Comprueba el resultado

Pulsa el botón **"Ver landing ↗"** arriba del todo para abrir la página en otra pestaña y ver cómo queda.

## 4. Foto o logo nuevos

En cada bloque con imagen puedes subir un archivo para ver cómo quedaría, pero ese cambio **no se guarda solo**: hay que avisar a quien mantiene la web para que sustituya el archivo definitivo y vuelva a publicar.

## 5. Cuando el texto ya sea el definitivo

Pulsa **"Exportar JSON"** arriba del todo. Se descarga un archivo con todo el contenido actual. Envíaselo a quien vaya a publicar la versión final, para que quede fija en la web y no dependa de tu navegador.

## Solicitudes de contacto

Las solicitudes que la gente envía desde el formulario **no aparecen en este panel**. Se guardan en Netlify (Site settings → Forms del proyecto), y Kodarvia configura el aviso por correo para que os llegue cada solicitud nueva.
